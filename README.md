# StepPoint Lite

iOS 17+ 向けの SwiftUI サンプルアプリです。当日の歩数を取得し、1000 歩ごとに 6 ポイント(最大 60 ポイント)を付与します。1 週間分の履歴を保存し、棒グラフで表示します。

## ビルド手順
1. Xcode 15 以降でこのリポジトリを開きます。
2. `StepPointLiteApp` をターゲットにビルド＆実行してください。初回起動時に歩数取得の許可を求められます。

## 権限について
- CoreMotion の歩数データへアクセスします。初回起動時に表示されるダイアログで許可してください。
- 拒否した場合はアプリ内に案内が表示され、設定アプリから再度許可できます。

## テストの実行
ターミナルから以下を実行します。
```
swift test
```
ポイント計算ロジックと日付ロールオーバーの単体テストが含まれています。
